# Тест-план Smart Voicing 0.1e

Версия: **Smart Voicing 0.1e — Distribution Modes + Gesture Classifier**.

Цель: проверить три режима распределения, различение Chord Gesture / Voice Gesture, корректную обработку 5+ входных нот, сохранение Voice Stack / legato / Sustain и восстановление выбранного режима после повторного открытия проекта.

## Базовая настройка

Использовать четыре downstream-инструмента:

```text
V1 / MIDI Ch1 → Trumpet
V2 / MIDI Ch2 → Tenor Sax
V3 / MIDI Ch3 → Trombone
V4 / MIDI Ch4 → Baritone Sax
```

Все четыре дорожки должны получать MIDI output Smart Voicing через соответствующий MIDI Input 1–4.

## 1. Режим «Сверху вниз»

Проверить последовательно 1, 2, 3 и 4 одновременно взятые ноты.

Ожидание:

```text
1 нота  → V1
2 ноты  → V1–V2
3 ноты  → V1–V3
4 ноты  → V1–V4
```

При четырёх нотах верхняя должна идти в V1, нижняя — в V4.

## 2. Режим «Снизу вверх»

Проверить 1–4 одновременно взятые ноты.

Ожидание:

```text
1 нота  → V4
2 ноты  → V3–V4
3 ноты  → V2–V4
4 ноты  → V1–V4
```

При четырёх нотах вертикальный порядок остаётся обычным: верхняя нота — V1, нижняя — V4.

## 3. Режим «Заполнить 4 голоса»

Проверить:

```text
1 нота C4
→ V1 C4 / V2 C4 / V3 C4 / V4 C4

2 ноты C4 G4
→ V1 G4 / V2 G4 / V3 C4 / V4 C4

3 ноты C4 E4 G4
→ V1 G4 / V2 E4 / V3 C4 / V4 C4

4 ноты C4 E4 G4 Bb4
→ V1 Bb4 / V2 G4 / V3 E4 / V4 C4
```

Важно: одна физическая нота должна корректно звучать сразу на нескольких Voice без зависших Note Off.

## 4. Пятинотный Chord Gesture

Почти одновременно взять пять нот, например:

```text
C4 E4 G4 Bb4 D5
```

Ожидание:

- активны максимум четыре независимых Voice;
- ни на одной downstream-дорожке не должна появляться «лишняя» вторая нота только потому, что входных нот пять;
- Router Monitor должен показывать `extra chord notes ignored: 1`;
- в режиме «Сверху вниз» используются четыре верхние ноты;
- в режиме «Снизу вверх» используются четыре нижние ноты;
- в режиме «Заполнить 4 голоса» при 4+ нотах используются четыре верхние.

Повторить с 6 нотами; счётчик ignored должен отражать лишние chord-notes.

## 5. Voice Gesture после сформированного аккорда

Взять четырёхнотный аккорд и удерживать его. Через заметную паузу сыграть отдельную новую ноту рядом с одним из Voice.

Ожидание:

- это не новый Chord Frame;
- новая нота назначается ближайшему Voice;
- она приходит на том же MIDI channel;
- соседние Voice не перескакивают;
- SWAM воспринимает overlap как legato / portamento gesture.

Проверить верхний, внутренний и нижний Voice.

## 6. Различие «пятая нота аккорда» и «движение голоса»

Сравнить два сценария:

A. Пять нот нажаты почти одновременно → это Chord Gesture → максимум 4 Voice.

B. Сначала устойчивый четырёхнотный аккорд, затем отдельная пятая нота через паузу → это Voice Gesture → continuation ближайшего Voice.

Это главный тест Gesture Classifier.

## 7. Sustain + новый аккорд

Сценарий:

```text
аккорд 1
→ pedal down
→ отпустить клавиши
→ сыграть аккорд 2, не отпуская pedal
→ pedal up
```

Ожидание:

- аккорд 2 звучит сразу;
- старые ноты не создают дополнительные самостоятельные Voice;
- после pedal-up остаётся новый физически удерживаемый аккорд;
- stuck notes отсутствуют.

Повторить во всех трёх Distribution Modes.

## 8. Смена Distribution Mode во время проекта

Переключить:

```text
Сверху вниз → Снизу вверх → Заполнить 4 голоса
```

Ожидание:

- старый routed frame корректно получает Note Off;
- текущие удерживаемые ноты перестраиваются по новому правилу;
- зависших нот нет;
- UI и Router Monitor показывают выбранный режим.

## 9. Сохранение режима

Выбрать, например, «Заполнить 4 голоса», сохранить проект, полностью закрыть Studio Pro и открыть проект снова.

Ожидание: Smart Voicing восстанавливает тот же Distribution Mode.

## 10. Быстрый стресс-тест

Поиграть:

- быстрые аккорды;
- legato отдельными голосами;
- 4–6 нотные chord gestures;
- Sustain down/up;
- повторные ноты;
- быстрые переключения между короткими аккордами.

После полного отпускания клавиш и педали все Voice Stack должны очиститься, зависших нот быть не должно.

## 11. CC / Pitch Bend / ARA regression

Expression, Vibrato/CC, Sustain и Pitch Bend должны продолжать доходить на Ch1–4. ARA Context Monitor должен одновременно правильно показывать Chord / Key / Time Signature / Tempo.

## 12. Запись результата

Записать downstream MIDI на четыре дорожки и проверить:

- в обычном четырёхголосии каждая дорожка содержит свой Voice;
- при Fill 4 допускается осознанное удвоение одной и той же входной ноты на нескольких дорожках;
- пятинотный Chord Gesture не создаёт случайный пятый самостоятельный голос;
- отдельный Voice Gesture записывается как legato-overlap в выбранном Voice.
