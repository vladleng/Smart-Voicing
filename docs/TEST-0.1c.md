# Smart Voicing 0.1c — тест Stable Voice Ownership + Sustain

Цель версии 0.1c: проверить, что Voice 1–4 сохраняют свою идентичность при движении отдельных голосов и что CC64 Sustain больше не разрушает распределение голосов.

## Схема маршрутизации

- Voice 1 → MIDI Channel/Input 1;
- Voice 2 → MIDI Channel/Input 2;
- Voice 3 → MIDI Channel/Input 3;
- Voice 4 → MIDI Channel/Input 4.

Начальное распределение формируется по высоте сверху вниз. После формирования полного четырёхголосного voicing или начала редактирования уже звучащего интервала/аккорда Router переходит в режим `STABLE` и сохраняет Voice slots.

## Подготовка

1. `Smart Voicing 0.1c` получает MIDI-клавиатуру.
2. Четыре destination tracks получают Smart Voicing как источник.
3. Назначить:
   - Trumpet → MIDI Input 1;
   - Tenor Sax → MIDI Input 2;
   - Trombone → MIDI Input 3;
   - Baritone Sax → MIDI Input 4.
4. Включить Monitor на всех четырёх.
5. Для теста Sustain использовать обычную педаль CC64.

## Тесты

### 1. Начальный четырёхголосный аккорд

Сыграть C4–E4–G4–C5.

Ожидание:

- V1/Ch1 → C5;
- V2/Ch2 → G4;
- V3/Ch3 → E4;
- V4/Ch4 → C4;
- Router Monitor переходит в `mode: STABLE`.

### 2. Верхний голос как мелодия

Удерживать нижние три ноты исходного аккорда. Отпустить только C5 и сыграть верхним голосом последовательность D5–E5–G5, каждый раз оставляя остальные три клавиши удержанными.

Ожидание:

- меняется только V1/Ch1;
- V2/Ch2, V3/Ch3 и V4/Ch4 не перескакивают между каналами;
- слышна только переатака верхнего инструмента.

### 3. Внутренний голос

Вернуться к четырём нотам. Удерживая V1, V3 и V4, отпустить ноту Voice 2 и сыграть другой нотой.

Ожидание: новая нота занимает V2/Ch2, остальные Voice slots не меняются.

Повторить то же для V3.

### 4. Нижний голос

Удерживая V1–V3, двигать только нижний голос.

Ожидание: меняется только V4/Ch4.

### 5. Пересечение голосов

После перехода в `STABLE` опустить мелодическую ноту V1 ниже текущей V2.

Ожидание: нота остаётся на V1/Ch1. В 0.1c приоритет имеет **идентичность Voice slot**, а не повторная сортировка по высоте. Ограничение crossing будет отдельной музыкальной политикой следующих этапов.

### 6. Sustain — основной баг 0.1b

Сыграть четыре ноты, нажать педаль Sustain и, не отпуская педаль, отпустить все клавиши.

Ожидание:

- все четыре инструмента продолжают звучать за счёт CC64;
- `keys held` становится 0;
- `sustain: DOWN`;
- V1–V4 остаются закреплены за своими нотами и не скатываются к нижнему голосу.

Отпустить педаль.

Ожидание:

- все четыре инструмента корректно замолкают;
- V1–V4 очищаются;
- `sustain: UP`;
- после полного освобождения Router готов к новому pitch-ranking кадру.

### 7. Sustain + повторное нажатие ноты

Сыграть аккорд, нажать Sustain, отпустить верхнюю клавишу и снова нажать её до отпускания педали.

Ожидание: верхняя нота повторно атакуется на том же V1/Ch1, соседние Voice slots не меняются.

### 8. Sustain + движение одного голоса

С педалью DOWN отпустить одну из четырёх клавиш и сыграть новую ноту тем же пальцем.

Ожидание: sustain-held старая нота сохраняет свой Voice slot до pedal-up. Если все четыре slots заняты, новая дополнительная нота не должна красть соседний Voice. После pedal-up освобождённый slot может быть назначен физически удерживаемой новой ноте.

Этот тест важен для определения дальнейшей политики re-articulation под Sustain.

### 9. Более четырёх нот в STABLE

После фиксации четырёх Voice нажать пятую ноту, не освобождая ни одного Voice.

Ожидание: существующие V1–V4 не меняются. Пятая нота не крадёт Voice slot. После освобождения одного Voice удерживаемая дополнительная нота может занять свободный slot.

### 10. CC / Expression / Pitch Bend

Удерживать четыре ноты и проверить Expression, Mod Wheel, Breath/другие используемые CC и Pitch Bend.

Ожидание: управляющие сообщения продолжают приходить на все четыре destination channels.

### 11. Быстрая игра и зависшие ноты

Несколько раз быстро:

- брать четырёхнотный аккорд;
- менять верхний и внутренние голоса;
- нажимать/отпускать Sustain;
- полностью отпускать клавиши и педаль.

Ожидание: после полного отпускания нет зависших нот, V1–V4 пусты.

### 12. ARA + Router

Во время тестов оставить `Smart Voicing ARA` активным и перемещать transport через Chord/Key changes.

Ожидание: Context Monitor продолжает работать независимо от MIDI Router.

### 13. Запись downstream MIDI

Если Studio Pro позволяет записать routed input на четыре destination tracks, записать короткий пример: аккорд + мелодия верхним голосом + Sustain.

Ожидание: каждая дорожка остаётся своей партией и не получает нот соседних Voice при движении мелодии.

## Что особенно важно сообщить

Критические пункты для 0.1c: **2, 3, 6, 7, 8, 11 и 13**.

Если возникает перескок или зависшая нота, полезно указать точную последовательность: какие ноты были удержаны, какая была отпущена/нажата и в каком состоянии находилась педаль.
