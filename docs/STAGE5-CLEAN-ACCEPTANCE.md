# Stage 5 — общая приёмка войсингов в Clean

**Статус:** выполнить после host-проверки Cluster 0.4i, до стабильной 0.5 / Stage 6. Использовать один проект и одинаковые мелодию, Chord Track, регистр и Voice routing для сравнения режимов.

**Задача:** проверить правильность вертикали и верность явно заданному аккорду. Clean не добавляет неуказанный цвет, но сохраняет явно записанные 9/11/13, sus, alterations и slash bass. На этом шаге не требуем слышимой разницы Color/Rich: их настройка с Voice Leading относится к Issue #10.

## Контрольные аккорды

- [ ] C, Cm, Cmaj7, Cm7, C7: правильные 3/7 и качество, V1 точно сыгранная мелодия.
- [ ] Cmaj9, C13, C7#11, C7(b9,b13): явно заданные тоны доступны в Clean; лишних случайных tensions нет.
- [ ] Bm7b5, C7b5, Caug, Csus2/Csus4: характерные b5/#5/sus не исчезают ради формы.
- [ ] Cmaj7/E и другой slash bass: заданный бас остаётся нижним там, где тип строит гармонический V4.
- [ ] Мелодия вне текущего аккорда: V1 сохраняется; нижние голоса не переопределяют Chord Track.
- [ ] Низкий MIDI и неполный набор кандидатов: безопасный неполный voicing/V1, без wrap, stuck notes и ложной ноты.

## Сравнить стратегию на одном и том же материале

| Тип | Проверить в Clean |
| --- | --- |
| Closed | Компактная форма, ясный аккорд; V1 сохранён. |
| Drop 2 / 3 / 2+4 | Те же выбранные Closed pitch classes; меняются октава и расположение. |
| Spread | Открытая вертикаль с структурной нижней опорой и guide tones. |
| Quartal | Узнаваемая квартовая структура, если разрешённые ноты это позволяют. |
| UST | Верхнее трезвучие и опорный V4, либо допустимая частичная форма. |
| Cluster | Плотность/секунды, если материал допускает, при сохранении chord identity. |
| Unison / Octaves / Doubling | Мелодические текстуры; не требовать гармонических tensions. |

- [ ] Переключения через UI/keyswitch и сохранённый проект не меняют музыкальный смысл выбранного режима.
- [ ] Зафиксировать конкретные аккорд, мелодию, ожидаемые/полученные V1–V4 для каждого расхождения; исправлять в своём слое (Stage 4 vocabulary или Stage 5 shape).

**Граница приёмки:** после исправления обнаруженных Clean-ошибок Stage 5 можно закрыть. Далее Stage 6 (#10) добавит Voice Leading и настройку Color/Rich для быстрой гармонизации базовых аккордов.
