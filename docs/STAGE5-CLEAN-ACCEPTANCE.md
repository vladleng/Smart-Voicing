# Stage 5 — общая приёмка войсингов в Clean

**Статус:** принято 2026-09-27 по восьми партитурам Clean, адресным проверкам исправлений в Studio Pro и регрессиям Harmony Core. Использован один проект и одинаковые мелодия, Chord Track, регистр и Voice routing для сравнения режимов. Стабильный checkpoint — 0.5.

Сравнение восьми присланных партитур Clean от 2026-09-27 и конкретные открытые вертикали: [Stage 5 Clean — review](STAGE5-CLEAN-EIGHT-VOICINGS-REVIEW-2026-09-27.md).

**Задача:** проверить правильность вертикали и верность явно заданному аккорду. Clean не добавляет неуказанный цвет, но сохраняет явно записанные 9/11/13, sus, alterations и slash bass. На этом шаге не требуем слышимой разницы Color/Rich: их настройка с Voice Leading относится к Issue #10.

Подробные правила построения и оговорки для каждого гармонического типа: [Stage 5 — правила гармонизации в Clean](STAGE5-CLEAN-HARMONIZATION-RULES.md).

## Контрольные аккорды

- [x] C, Cm, Cmaj7, Cm7, C7: правильные 3/7 и качество, V1 точно сыгранная мелодия.
- [x] Cmaj9, C13, C7#11, C7(b9,b13): явно заданные тоны доступны в Clean; лишних случайных tensions нет. В четырёх голосах все перечисленные расширения не обязаны звучать одновременно; дубли вместо доступной характерной ♭9 в `G7♭9` исправлены.
- [x] Bm7b5, C7b5, Caug, Csus2/Csus4: характерные b5/#5/sus не исчезают ради формы.
- [x] Cmaj7/E и другой slash bass: заданный бас остаётся нижним там, где тип строит гармонический V4. Для обращений maj7 корень сохранён при доступности; `Cmaj7/G` с G одновременно в V1 и V4 остаётся осознанно неполным четырёхголосным аккордом.
- [x] Мелодия вне текущего аккорда: V1 сохраняется; нижние голоса не переопределяют Chord Track.
- [x] Низкий MIDI и неполный набор кандидатов: безопасный неполный voicing/V1, без wrap, stuck notes и ложной ноты (host-проверка нижнего регистра ограничена диапазоном инструмента, core regression пройдена).

## Сравнить стратегию на одном и том же материале

| Тип | Проверить в Clean |
| --- | --- |
| Closed | Компактная форма, ясный аккорд; V1 сохранён. |
| Drop 2 / 3 / 2+4 | Те же выбранные Closed pitch classes; меняются октава и расположение. |
| Spread | Открытая вертикаль с структурной нижней опорой и guide tones. |
| Quartal | Узнаваемая квартовая структура, если разрешённые ноты это позволяют. |
| UST | Верхнее трезвучие и опорный V4, либо допустимая частичная форма. |
| Cluster | Плотность/секунды, если материал допускает, при сохранении chord identity. |
| Unison / Octaves / Doubling | Мелодические текстуры; не требовать гармонических tensions. |

- [x] Переключения через UI/keyswitch и сохранённый проект не меняют музыкальный смысл выбранного режима.
- [x] Конкретные аккорд, мелодия и V1–V4 для расхождений зафиксированы в review; ошибки slash, UST/13 и `G7♭9` исправлены в Stage 5 shape/scoring и проверены повторно.

**Граница приёмки:** после исправления обнаруженных Clean-ошибок Stage 5 можно закрыть. Далее Stage 6 (#10) добавит Voice Leading и настройку Color/Rich для быстрой гармонизации базовых аккордов.

**Итог host-проверки:** после последнего фикса в такте 8 на второй ноте `G7♭9` Spread даёт F–B–A♭–G, Quartal — F–B–F–A♭ (от верхнего голоса к нижнему). A♭ сохранена в обоих режимах; Quartal использует rootless опору. Приоритет геометрии Quartal, отсутствие корня и звучание низкой A♭ остаются музыкальными нюансами для последующих этапов, но явный аккорд не превращается в обычный G7.
