# Smart Voicing 0.4c3 — Doubling host checklist

Use the latest `Smart-Voicing-0.4c-Windows` artifact after the host-integration CI is green.

## Studio Pro smoke test

1. Open Smart Voicing in `Melody Harmonize` mode.
2. Select `Voicing Type = Doubling`.
3. Record a short monophonic melody in a normal register.
4. Verify the output layout relative to V1 is exactly:

```text
Ch1 / V1 = melody
Ch2 / V2 = melody
Ch3 / V3 = melody - 12
Ch4 / V4 = melody - 12
```

5. Confirm Ch1/Ch2 remain two independent MIDI parts at the same pitch.
6. Confirm Ch3/Ch4 remain two independent MIDI parts one octave below.
7. Change `Clean / Color / Rich`: Doubling pitches must remain unchanged.
8. Cross Chord Track boundaries while holding a melody note: Doubling pitches must not reharmonize.
9. Repeat the same melody pitch several times: all four active voices must rearticulate cleanly.
10. Release the melody: every active voice must receive Note Off; no stuck notes.
11. Switch live `Closed → Drop 2 → Unison → Octaves → Doubling → Closed` while a note is sounding: V1 stays performer-owned and no stale/tiny garbage notes appear.
12. Save with `Doubling`, reopen the project, and verify `Doubling` is restored.
13. Open an older project saved with Closed / Drop 2 / Unison / Octaves and verify its prior Voicing Type is preserved.
14. Confirm Tension keyswitch notes remain swallowed and do not appear on downstream instrument tracks.
15. Switch back to Closed/Drop 2 and confirm normal Clean/Color/Rich harmonic behaviour returns.
16. Repeat playback once and confirm generated MIDI is identical.

## Optional low-register safety check

Play a melody below MIDI note 12. V1/V2 remain on the performer melody while V3/V4 become inactive if `melody - 12` is outside the MIDI domain. No voice may wrap upward automatically. Register adaptation remains Stage 7.

## Pass condition

0.4c3 is accepted when Doubling behaves as deterministic paired unison texture `[0,0,-12,-12]`, remains independent of Harmony/Tension selection, persists through save/reopen, and switches cleanly against Closed, Drop 2, Unison and Octaves without stuck or garbage MIDI.
