# Smart Voicing 0.0g — контрольный тест границ

Цель версии 0.0g — проверить и устранить микробаг выбора предыдущего гармонического события, когда курсор Studio Pro визуально стоит точно на начале нового аккорда / тональности / размера, но transport PPQ и ARA event position отличаются на микроскопическую floating-point величину.

## Что изменено

- Для Chord / Key / Time Signature используется единый `boundary tolerance = 0.0001 PPQ`.
- События остаются start-inclusive: на самой границе должен выбираться новый контекст.
- В Instrument добавлена строка `Boundary diag` с PPQ до 9 знаков, ближайшим chord event и delta.
- Позиции в harmonic maps выводятся с повышенной точностью.

## Минимальный контрольный тест

1. Найти два соседних аккорда, например `D → C`, где смена происходит ровно на начале такта.
2. Поставить курсор немного левее границы. Должен отображаться `D`.
3. Поставить курсор визуально точно на начало `C`. Должен отображаться `C`.
4. Зафиксировать строку `Boundary diag`: особенно `PPQ`, `nearest chord` и `delta`.
5. Поставить курсор немного правее границы. Должен продолжать отображаться `C`.
6. Повторить тест на нескольких границах Chord Track.
7. Повторить тот же принцип на границе Key Signature.
8. Повторить тот же принцип на границе Time Signature.

Ожидаемое правило:

```text
до границы    → предыдущий контекст
на границе    → новый контекст
после границы → новый контекст
```

Если на визуальной границе снова выбирается предыдущее событие, сохранить скриншот с `Boundary diag`. По `delta` можно будет подобрать корректный tolerance без догадок.
