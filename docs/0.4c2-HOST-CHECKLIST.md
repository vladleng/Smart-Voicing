# Smart Voicing 0.4c2 — Octaves host checklist

Use the latest `Smart-Voicing-0.4c-Windows` artifact after the host-integration CI is green.

## Studio Pro smoke test

1. Open Smart Voicing in `Melody Harmonize` mode.
2. Select `Voicing Type = Octaves`.
3. Record a short monophonic melody in a comfortable register.
4. Verify the output layout relative to V1 is exactly:

```text
Ch1 / V1 = melody
Ch2 / V2 = melody - 12
Ch3 / V3 = melody - 12
Ch4 / V4 = melody - 24
```

5. Confirm Ch2 and Ch3 both remain present as independent MIDI parts even though they use the same pitch.
6. Change `Clean / Color / Rich`: Octaves pitches must remain unchanged.
7. Cross Chord Track boundaries while holding a melody note: Octaves pitches must not reharmonize.
8. Repeat the same melody pitch several times: all active octave voices must rearticulate cleanly.
9. Release the melody: all active voices must receive Note Off; no stuck notes.
10. Switch live `Closed → Drop 2 → Unison → Octaves → Closed` while a note is sounding: V1 remains the performer melody and no stale/tiny garbage notes appear.
11. Save with `Octaves`, reopen the project, and verify `Octaves` is restored.
12. Open an older 0.4a/0.4b project and verify its saved `Closed` / `Drop 2` selection is preserved.
13. Confirm Tension keyswitch notes remain swallowed and do not appear on downstream instrument tracks.
14. Switch back to Closed/Drop 2 and confirm normal Clean/Color/Rich harmonic behaviour returns.
15. Repeat playback once and confirm the generated MIDI is identical.

## Optional low-register safety check

Play a melody low enough that `melody - 24` would fall below MIDI note 0. The out-of-range lower Voice must stay inactive rather than wrap upward or move V1. This is a Stage 5 safety rule; automatic instrument/range adaptation belongs to Stage 7.

## Pass condition

0.4c2 is accepted when Octaves behaves as the deterministic melodic-section layout `[0,-12,-12,-24]`, remains independent of Harmony/Tension selection, persists through save/reopen, and switches cleanly against Closed, Drop 2 and Unison without stuck or garbage MIDI.
