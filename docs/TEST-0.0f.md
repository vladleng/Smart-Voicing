# Smart Voicing 0.0f — чек-лист тестирования

Цель этой итерации — полностью проверить транспорт и live harmonic context перед выпуском 0.1.

## Подготовка проекта

Создай один тестовый проект Studio Pro с такой структурой:

- Audio Event с `Smart Voicing ARA` в Event FX;
- Instrument Track с `Smart Voicing`;
- не менее 6–8 аккордов в Chord Track;
- минимум 3 участка Key Track, например `C major → A minor → F major`;
- минимум 4 смены размера, например `4/4 → 3/4 → 5/4 → 4/4`;
- несколько точек Tempo Track.

Открой одновременно окна `Smart Voicing ARA` и `Smart Voicing`.

Перед началом проверь базовые признаки:

```text
Smart Voicing ARA: CONNECTED
Host content access: YES
Musical contexts: 1
Key Signatures: AVAILABLE
Sheet Chords: AVAILABLE
Tempo Entries: AVAILABLE
Bar Signatures: AVAILABLE
```

## Тест 1 — Transport revision в STOP

1. Останови playback.
2. Не трогай playhead 10–15 секунд.
3. Запомни `Transport rev` в Instrument.
4. Убедись, что число не растёт само по себе.

Ожидаемый результат: `Transport rev` остаётся постоянным.

## Тест 2 — ручное перемещение playhead в STOP

1. В STOP щёлкни playhead в другое место проекта.
2. Проверь PPQ и seconds в Instrument.
3. Проверь `Transport rev`.
4. Ничего больше не делай несколько секунд.

Ожидаемый результат: позиция обновляется, `Transport rev` увеличивается один раз на фактическое изменение и затем снова остаётся стабильным.

## Тест 3 — playback

1. Запусти playback через несколько аккордов.
2. Следи за PPQ, текущим аккордом, тональностью, размером и темпом.
3. Останови playback.

Ожидаемый результат: Context Monitor следует за playhead; после STOP фиксируется последняя позиция и revision перестаёт расти.

## Тест 4 — граница аккорда

Для одной границы между двумя разными аккордами проверь три позиции:

- непосредственно перед границей;
- точно на границе;
- сразу после границы.

Ожидаемый результат: до границы активен предыдущий аккорд, на границе и после неё — новый.

Повтори на 2–3 разных сменах аккордов.

## Тест 5 — live update Chord Track

При открытых плагинах:

1. замени существующий аккорд;
2. добавь новый;
3. перемести существующий;
4. удали один аккорд.

Ожидаемый результат: `Harmony rev` увеличивается после каждого изменения, карты и текущий аккорд обновляются без Reload.

## Тест 6 — live update Key Track

При открытых плагинах:

1. добавь новую смену тональности;
2. измени существующую;
3. перемести её;
4. удали одну смену.

Ожидаемый результат: `Harmony rev` увеличивается, `Key map` обновляется, Context Monitor сразу показывает правильную активную тональность.

## Тест 7 — live update Time Signature

Повтори тот же сценарий для размера:

1. добавь смену размера;
2. измени размер, например `3/4 → 5/4`;
3. перемести точку смены;
4. удали одну смену.

Ожидаемый результат: `Harmony rev` увеличивается, `Time-signature map` обновляется без Reload.

## Тест 8 — несколько смен Key и Time Signature

Сделай в одном проекте, например:

```text
Key:  C major → A minor → F major → D minor
Time: 4/4 → 3/4 → 5/4 → 4/4
```

Перемещай playhead по всем участкам в STOP и затем проиграй их.

Ожидаемый результат: Instrument выбирает событие по позиции, а не одно глобальное значение проекта.

## Тест 9 — одновременная смена контекста

В одной точке таймлайна одновременно поменяй:

- аккорд;
- Key Signature;
- Time Signature.

Поставь playhead до точки и после неё.

Ожидаемый результат: после обновления Instrument показывает согласованный новый Chord / Key / Time Signature из одной актуальной карты; не должно быть длительного состояния, где часть данных новая, а часть старая.

## Тест 10 — границы Audio Event

Оставь `Smart Voicing ARA` на коротком Audio Event и перемести playhead далеко за его пределы.

Ожидаемый результат: Context Monitor и live update Chord / Key / Time Signature продолжают работать. Это повторная проверка уже подтверждённого поведения.

## Тест 11 — сохранение и повторное открытие проекта

1. Сохрани проект с обоими плагинами.
2. Закрой Studio Pro.
3. Открой проект заново.
4. Не делай ручной Reload.

Ожидаемый результат:

- `Smart Voicing ARA` снова получает Musical Context;
- Instrument снова показывает `CONNECTED`;
- карты Chord / Key / Time Signature / Tempo совпадают с проектом;
- Context Monitor показывает правильное значение после перемещения playhead или старта playback.

## Что прислать после теста

Достаточно сообщить результат по номерам, например:

```text
1 — OK
2 — OK
3 — OK
4 — ошибка на точной границе
5 — OK
...
```

Если какой-то тест не проходит, приложи скрин обоих окон плагинов и напиши, что именно менял в Studio Pro.
