# Smart Voicing 0.2d — контрольный тест

Цель версии: при удержанной melody note автоматически перестраивать сгенерированные нижние голоса на границе нового Chord Track без нового Note On от пользователя.

## Что добавляем

- отслеживание активного Chord context во время playback;
- хранение активной melody note как приоритетного V1;
- автоматический пересчёт V2–V4 при смене текущего аккорда;
- корректную замену старых сгенерированных нот через Note Off / Note On;
- защиту от stuck notes при последовательных сменах аккордов;
- диагностическое отображение текущего chord revision / факта reharmonization;
- unit-тесты на последовательность нескольких аккордов при одной удержанной melody note.

## Базовое правило 0.2d

```text
V1 = сыгранная и удерживаемая melody note
V2–V4 = заново рассчитанный базовый Close voicing из текущего Chord Track
```

При смене Chord Track V1 не меняется. V2–V4 перестраиваются только если изменился активный гармонический контекст.

Пример:

```text
Удерживаем G4

Cmaj7 → Fmaj7 → Dm7 → G7

V1 всё время = G4
V2–V4 автоматически перестраиваются на каждой границе аккорда
```

## Что сознательно не входит в 0.2d

- полноценный voice leading между соседними voicings;
- Drop 2 / Drop 3 и другие jazz voicings;
- instrument ranges;
- автоматический выбор scale/mode;
- полноценная Sustain Chord Morph / Voice Stack интеграция для сгенерированной гармонии — это 0.2e;
- финальная transport regression / Panic / UI hardening.

То есть в 0.2d каждый новый аккорд пока пересчитывается тем же базовым Close Harmonizer, что появился в 0.2c. Цель версии — не сделать движение голосов красивым, а доказать сам механизм live reharmonization по Chord Track.

## Автоматические тесты

CI должен подтвердить как минимум:

1. удержанная melody note не меняется при смене аккорда;
2. нижние Voice меняются при изменении Chord context;
3. повторный snapshot того же аккорда не создаёт лишних Note Off / Note On;
4. несколько последовательных chord changes не оставляют старые сгенерированные ноты активными;
5. `(no chord)` переводит гармонизацию в безопасный fallback;
6. возвращение валидного аккорда снова создаёт V2–V4;
7. тесты 0.2b и 0.2c продолжают проходить.

## Ручной тест в Studio Pro

1. Выбрать `Melody Harmonize`.
2. Создать последовательность Chord Track, например `Cmaj7 | Fmaj7 | Dm7 | G7`.
3. Нажать и удерживать одну ноту, например `G4`.
4. Запустить playback через всю последовательность.
5. Проверить:
   - V1 / Ch1 остаётся G4;
   - V2–V4 меняются точно на границах аккордов;
   - не требуется повторно нажимать G4;
   - нет зависших старых нот;
   - после остановки/отпускания melody note сгенерированные голоса корректно выключаются.

## Критерий прохождения 0.2d

Версия подтверждается после успешного Windows CI и пользовательского теста в Studio Pro, где одна удержанная melody note корректно reharmonize-ится при нескольких сменах Chord Track без stuck notes.
