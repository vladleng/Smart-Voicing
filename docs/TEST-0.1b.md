# Smart Voicing 0.1b — тест Direct 4 Voice Router

Цель версии 0.1b: проверить первый реальный MIDI Router в Studio Pro.

## Схема маршрутизации

`Smart Voicing` выдаёт один VST3 MIDI/Event output. Голоса разделяются по MIDI-каналам:

- Voice 1 → Channel 1 — верхняя удерживаемая нота;
- Voice 2 → Channel 2 — вторая сверху;
- Voice 3 → Channel 3 — третья сверху;
- Voice 4 → Channel 4 — четвёртая сверху.

Для 1–3 нот используются только соответствующие верхние Voice. Если удерживается больше четырёх нот, в этой итерации маршрутизируются четыре верхние ноты; остальные остаются во входном состоянии и могут войти в Voice 4 после отпускания более высокой ноты.

CC, Pitch Bend, Channel Pressure, Poly Pressure, Program Change и другие channel MIDI-сообщения дублируются на Channels 1–4. System messages проходят один раз без изменения. CC120/CC123 также очищают внутреннее состояние удерживаемых нот.

## Подготовка Studio Pro

1. На source track загрузить `Smart Voicing 0.1b` и подать на него MIDI-клавиатуру.
2. Создать четыре destination instrument tracks.
3. Для каждой destination track выбрать `Smart Voicing / MIDI Output 1` как источник.
4. Назначить входы/каналы:
   - Trumpet → MIDI Input/Channel 1;
   - Tenor Sax → MIDI Input/Channel 2;
   - Trombone → MIDI Input/Channel 3;
   - Baritone Sax → MIDI Input/Channel 4.
5. Включить Monitor на нужных дорожках.

## Тесты

### 1. Одна нота

Сыграть одну ноту.

Ожидание: звучит только Voice 1 / Channel 1. В UI `V1/Ch1` показывает ноту, V2–V4 пусты.

### 2. Две, три и четыре ноты

Сыграть устойчивые интервалы/аккорды по 2, 3 и 4 ноты.

Ожидание: ноты сортируются сверху вниз. При четырёх нотах каждый из четырёх инструментов играет ровно одну свою ноту.

### 3. Контроль порядка

Сыграть, например, C4–E4–G4–C5.

Ожидание:

- Voice 1 / Ch1 → C5;
- Voice 2 / Ch2 → G4;
- Voice 3 / Ch3 → E4;
- Voice 4 / Ch4 → C4.

### 4. Отпускание одной ноты

Удерживать четыре ноты и отпустить одну из середины.

Ожидание: более низкие голоса пересортируются, старые назначения получат Note Off, новые — Note On. Не должно оставаться зависших нот.

### 5. Более четырёх нот

Удерживать пять нот.

Ожидание: звучат четыре верхние. Отпустить одну из верхних четырёх — ранее игнорировавшаяся пятая нота должна войти в свободный нижний Voice.

### 6. Быстрые аккорды

Несколько раз быстро сыграть и полностью отпустить четырёхнотные аккорды.

Ожидание: после полного отпускания клавиш все четыре инструмента молчат, UI показывает V1–V4 как `—`, зависших нот нет.

### 7. Expression / CC

Удерживая четыре ноты, двигать Expression/Mod Wheel и Sustain.

Ожидание: управляющие сообщения приходят на все четыре канала. В MIDI Probe растёт счётчик CC. Sustain пока не участвует в алгоритме распределения голосов — он просто передаётся инструментам.

### 8. Pitch Bend

Удерживая четыре ноты, использовать Pitch Bend.

Ожидание: bend слышен на всех четырёх инструментах, счётчик Pitch Bend выводится нормальным числом без странных символов.

### 9. ARA + Router

Оставить `Smart Voicing ARA` на ARA-якоре и во время игры двигать transport через Chord/Key changes.

Ожидание: Context Monitor продолжает обновляться независимо от MIDI Router.

### 10. Запись

Если Studio Pro позволяет, записать выход Smart Voicing на четыре destination tracks.

Ожидание: каждая дорожка получает только свой MIDI channel / Voice и записывает отдельную одноголосную партию.

## Что важно прислать после теста

Особенно полезны результаты пунктов 2, 4, 6, 7, 8 и 10. Если появляется зависшая нота, указать последовательность нажатий/отпусканий, которая её вызвала.
