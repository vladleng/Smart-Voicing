# Smart Voicing 0.4f — Studio Pro Host Checklist

Use the latest green `Smart-Voicing-0.4f-Windows` artifact after full host-integration CI. This is a separate check from the core CI.

## Setup

- Load Smart Voicing and Smart Voicing ARA into the known-good Studio Pro project.
- Melody Harmonize is active; Chord Track and Sound Variations map MIDI 32..47 are available.
- Keep the same melody and chords while switching voicing types.

## Required checks

- [ ] `B0 / MIDI 35` selects Spread, and the Voicing Type box follows immediately.
- [ ] MIDI 35 Note On/Off is swallowed and does not reach downstream instruments.
- [ ] V1 is exactly the played melody, including a non-chord note.
- [ ] On Cmaj7 and a minor seventh chord, V4 anchors the root; 3 and 7 remain audible when the vertical permits them.
- [ ] A slash chord anchors its explicit bass pitch class at V4.
- [ ] A m7b5 example keeps its characteristic b5; explicit alterations stay in the Stage 4 candidate vocabulary.
- [ ] Compare Closed / Drop family / Spread on the same melody: Spread is more open and can use different chord-tone choices, while Chord Track authority is preserved.
- [ ] Clean / Color / Rich and a confirmed V7 → minor keep their Stage 4 meaning; an unresolved dominant does not gain an assumed target.
- [ ] Switching `Closed ↔ Spread ↔ Drop 2+4 ↔ Unison` during a held melody creates no stuck or tiny notes.
- [ ] Existing MIDI 36..47 controls and future reserved MIDI 32..34 remain unchanged.
- [ ] Save with Spread selected, reopen, and verify the selection.
- [ ] Repeat playback with identical inputs/state and confirm identical MIDI output.
- [ ] Low melody with no safe bass anchor leaves V1 only, with no wrapped note.

0.4f becomes **ACCEPTED** only after these host checks pass. Stage 6 voice continuity and Stage 7 instrument-specific range adaptation are not part of this slice.
