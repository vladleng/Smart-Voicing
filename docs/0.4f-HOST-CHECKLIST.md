- [x] Switching `Closed ↔ Spread ↔ Drop 2+4 ↔ Unison` during a held melody creates no stuck or tiny notes.
- [x] Existing MIDI 36..47 controls and future reserved MIDI 32..34 remain unchanged.
- [x] Save with Spread selected, reopen, and verify the selection.
- [x] Repeat playback with identical inputs/state and confirm identical MIDI output.
