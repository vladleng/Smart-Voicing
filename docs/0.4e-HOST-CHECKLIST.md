# Smart Voicing 0.4e — Studio Pro Host Checklist

Target: **Drop 2+4 host acceptance**

Artifact: `Smart-Voicing-0.4e-Windows`

## Primary test

1. Load `Smart Voicing 0.4e` + `Smart Voicing ARA` in the same known-good Studio Pro test project.
2. Use `Melody Harmonize`.
3. Select the same melody/chord and compare:
   - Closed;
   - Drop 2;
   - Drop 3;
   - Drop 2+4.
4. Trigger `D#1 / MIDI 39` through the already configured Sound Variation.
5. Confirm UI immediately shows `Drop 2+4`.

Expected Drop 2+4 contract:

```text
Closed = [V1, V2, V3, V4]
Drop 2+4 source pitches = [V1, V2-12, V3, V4-12]
V1 stays unchanged
V2..V4 are sorted into sounding top-down order
pitch classes stay identical to Closed
```

## Required acceptance checks

- [ ] `D#1 / MIDI 39` selects Drop 2+4.
- [ ] Voicing Type ComboBox follows MIDI 39.
- [ ] MIDI 39 Note On/Off is swallowed and does not sound downstream.
- [ ] Closed and Drop 2+4 use the same pitch-class vocabulary.
- [ ] V1 melody remains identical.
- [ ] Closed V2 is present one octave lower in Drop 2+4.
- [ ] Closed V4 is present one octave lower in Drop 2+4.
- [ ] lower output slots remain in actual sounding top-down order.
- [ ] Clean / Color / Rich retain their accepted harmonic meaning.
- [ ] confirmed V7 → minor remains target-aware before the Drop transform.
- [ ] slash-bass case retains the explicit bass pitch class as the lowest member when the transform is valid.
- [ ] switching `Closed ↔ Drop 2 ↔ Drop 3 ↔ Drop 2+4` while playing creates no stuck or tiny notes.
- [ ] switching onward to `Unison / Octaves / Doubling` still works.
- [ ] existing Tension keyswitches 43/44/45 remain unchanged.
- [ ] Harmony Mode keyswitches 46/47 remain unchanged.
- [ ] save/reopen with Drop 2+4 selected restores Drop 2+4.
- [ ] repeated playback with identical input/state is deterministic.

## Suggested musical material

Use at least:

- one ordinary major seventh chord;
- one minor seventh chord;
- one major II–V–I;
- one minor II–V–I;
- one confirmed dominant resolving to minor;
- one explicit slash-bass chord.

The purpose is not to re-test Stage 4 from scratch. It is to verify that Drop 2+4 only changes the vertical shape of the already accepted harmonic material.

## Acceptance

0.4e can be marked **ACCEPTED / COMPLETED** when the current Windows host candidate is green and the checklist above passes in Studio Pro without a regression in the accepted keyswitch workflow.
