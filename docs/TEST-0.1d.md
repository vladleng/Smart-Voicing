# Smart Voicing 0.1d — тест Voice Stack / Legato / Sustain Chord Morph

Цель версии 0.1d: проверить, что каждый Voice 1–4 ведёт себя как отдельный монофонический исполнитель с собственным стеком нот, а Sustain больше не блокирует переход к следующему аккорду.

## Подготовка

Использовать ту же схему Studio Pro:

- Voice 1 / MIDI Input 1 → Trumpet;
- Voice 2 / MIDI Input 2 → Tenor Sax;
- Voice 3 / MIDI Input 3 → Trombone;
- Voice 4 / MIDI Input 4 → Baritone Sax.

В Router Monitor для каждого Voice показывается текущая верхняя нота и глубина `[stack N]`.

## Тесты

### 1. Базовый четырёхголосный voicing

Сыграть C4–E4–G4–C5.

Ожидание: V1=C5, V2=G4, V3=E4, V4=C4; Router переходит в STABLE; глубина каждого стека = 1.

### 2. Legato верхнего голоса

Не отпуская C5, нажать D5, затем отпустить C5.

Ожидание: D5 идёт на V1/Ch1; V2–V4 не меняются. В момент перекрытия stack V1 должен кратковременно стать 2. SWAM должен воспринимать переход как legato/portamento gesture без новой партии на соседнем Voice.

### 3. Возврат по mono note stack

Удерживать C5, нажать D5, затем отпустить D5, продолжая держать C5.

Ожидание: D5 звучит как верхняя нота V1, а после её отпускания инструмент возвращается к C5 без изменения V2–V4.

### 4. Legato внутренних и нижнего Voice

Повторить overlap-смену отдельно для V2, V3 и V4.

Ожидание: каждая новая нота остаётся на том же MIDI channel/Voice; соседние голоса не перескакивают.

### 5. Дальний переход / portamento candidate

На одном Voice сделать заметный скачок при перекрытии клавиш, например V1 C5 → G5.

Ожидание: новая нота остаётся на V1/Ch1. Характер glide/portamento определяется настройками destination instrument; Smart Voicing не генерирует искусственный Pitch Bend.

### 6. Sustain: переход к следующему аккорду

Сыграть аккорд 1 → нажать Sustain → отпустить его клавиши → не отпуская Sustain сыграть аккорд 2.

Ожидание: аккорд 2 начинает звучать сразу, педаль больше не «замораживает» старый voicing. В каждом Voice старый sustain-held тон остаётся ниже в stack, новый становится верхним.

### 7. Pedal-up оставляет новый зажатый аккорд

Продолжая тест 6, держать клавиши аккорда 2 и отпустить Sustain.

Ожидание: старые sustain-held ноты получают Note Off и удаляются из stack; аккорд 2 продолжает звучать, потому что его клавиши физически удерживаются.

### 8. Классическое перекрытие педалью

Играть последовательность аккордов с обычной техникой: pedal down перед сменой, новый аккорд, затем pedal up после взятия нового аккорда.

Ожидание: переходы плавные; старые ноты живут только до pedal-up, новые физически удерживаемые ноты остаются.

### 9. Повтор той же sustain-held ноты

Под Sustain отпустить ноту, затем снова нажать ту же клавишу.

Ожидание: она переатакуется на том же Voice/channel и становится верхней записью своего Voice stack без перескока соседних Voice.

### 10. Пятая нота в STABLE

При четырёх активных Voice нажать дополнительную ноту, не отпуская ближайшую старую.

В 0.1d это трактуется как legato continuation ближайшего Voice, а не как пятый независимый голос. Проверить, что канал выбирается музыкально ожидаемо. Если выбор неоднозначен — записать исходные четыре ноты и пятую ноту для доработки resolver.

### 11. Быстрые переходы и отсутствие stuck notes

Поиграть быстрые legato-фразы каждым Voice, смены аккордов под Sustain, короткие и длинные педали.

Ожидание: после полного отпускания клавиш и педали V1–V4 очищаются, stack depth = 0, зависших нот нет.

### 12. CC / Pitch Bend / ARA

Проверить Expression, Mod Wheel, Pitch Bend и одновременную работу Context Monitor.

Ожидание: поведение 0.1c не регрессировало; ARA Context продолжает обновляться параллельно Router.

### 13. Запись downstream MIDI

Если workflow Studio Pro позволяет, записать четыре routed партии.

Особенно полезен пример: устойчивый аккорд + legato-мелодия верхним голосом + смена аккорда под Sustain.

## Что особенно важно сообщить

- пункт 2: действительно ли SWAM воспринимает overlap как legato;
- пункт 4: насколько точно nearest-Voice resolver угадывает внутренние голоса;
- пункты 6–8: естественно ли ощущается новая Sustain-модель;
- пункт 10: когда пятая нота должна быть continuation, а когда её лучше игнорировать;
- любые зависшие ноты с точной последовательностью Note/Sustain действий.
