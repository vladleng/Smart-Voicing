# Smart Voicing — Tension Level

**Status:** Accepted in Smart Voicing 0.4 / Stage 4  
**Related Issues:** #8, #10, #24, #25, #28, #29

Final accepted contract:

```text
Clean → structural chord identity
Color → functionally natural / inside colour for the REAL target
Rich  → functionally intensified tension / altered colour
```

```text
No next chord
→ no assumed resolution target

Real next chord
→ target-aware Functional Tension Profile
```

Explicit Chord Track always outranks inference. Characteristic tones such as `m7b5 b5`, augmented `#5`, sus identity and explicit altered fifth are protected. For confirmed `V→minor`, `b13` can be Color while stronger `b9/#9/#11` material belongs to Rich vocabulary; natural 13 is not an automatic inferred default.

See `docs/CONCEPT.md`, `docs/FUNCTIONAL-TENSION-PROFILES.md`, and `docs/TEST-0.4.md` for full details.
