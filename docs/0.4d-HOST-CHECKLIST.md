# Smart Voicing 0.4d — Studio Pro Host Checklist

Target: **Drop 3 host acceptance**

Use the latest green artifact named `Smart-Voicing-0.4d-Windows`.

## Setup

- Smart Voicing ARA is connected and Chord Track context is visible.
- Smart Voicing is in `Melody Harmonize`.
- Existing Sound Variations map is loaded.
- `D1 / MIDI 38` is the existing `Drop 3` variation.

## Tests

### 1. Selection / UI

- Trigger `D1 / MIDI 38`.
- UI `Voicing Type` must show `Drop 3`.
- Trigger `C1 / MIDI 36` and `C#1 / MIDI 37` to confirm Closed and Drop 2 still work.
- Return to `D1 / MIDI 38`.

### 2. Mechanical Drop 3 rule

For one stable chord and melody note:

1. record/inspect the Closed four-voice result;
2. switch to Drop 3;
3. V1 must stay the same melody pitch;
4. the pitch corresponding to Closed V3 must appear one octave lower;
5. all four pitch classes must be the same as Closed;
6. V2..V4 should remain arranged in sounding top-down order.

Score/piano-roll inspection is acceptable. MIDI note numbers are preferable if octave labels are ambiguous.

### 3. Harmonic vocabulary preservation

Repeat on:

- major II–V–I;
- minor II–V–I;
- confirmed V7→minor in Color and Rich;
- unresolved dominant;
- explicit altered dominant if available.

Drop 3 must reorganize the Closed material only. It must not invent a different tension vocabulary.

### 4. Tension controls

With Drop 3 active:

- `G1 / MIDI 43` → Clean;
- `G#1 / MIDI 44` → Color;
- `A1 / MIDI 45` → Rich.

The musical differences should follow the same Stage 4 rules already accepted for Closed/Drop 2.

### 5. Slash-bass safety

On an explicit slash-bass chord such as `Cmaj7/E` or another clear test case:

- Drop 3 should safely fall back to the accepted Closed vertical for the current MVP;
- the explicit bass must remain authoritative.

### 6. Live switching hygiene

While a melody is held or during a quantized phrase, switch:

```text
Closed → Drop 2 → Drop 3 → Unison → Octaves → Doubling → Closed
```

Expected:

- no stuck notes;
- no tiny accidental notes;
- V1 remains performer-owned;
- only the required lower voices change for harmonic strategies.

### 7. Keyswitch swallowing

`D1 / MIDI 38` Note On and Note Off must not reach downstream instruments as musical notes.

### 8. Project persistence

- select Drop 3;
- save project;
- close/reopen;
- Drop 3 must still be selected.

Existing older project selections must remain unchanged because enum values `0..4` were not renumbered.

### 9. Regression of established performance map

Confirm these remain unchanged:

```text
36 C1   Closed
37 C#1  Drop 2
38 D1   Drop 3
39 D#1  Drop 2+4 RESERVED
40 E1   Unison
41 F1   Octaves
42 F#1  Doubling
43 G1   Clean
44 G#1  Color
45 A1   Rich
46 A#1  Direct Router
47 B1   Melody Harmonize
```

### 10. Determinism

Play the same passage several times with the same project state. Generated MIDI pitches must be identical each time.

## Acceptance

0.4d is accepted when the Drop 3 rule, harmonic-vocabulary preservation, keyswitch behavior, live switching, persistence and regression checks above pass in Studio Pro.
