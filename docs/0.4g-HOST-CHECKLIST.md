# Smart Voicing 0.4g — Studio Pro Quartal checklist

Use the latest green `Smart-Voicing-0.4g-Windows` artifact with Smart Voicing and Smart Voicing ARA.

## Musical checks

- [ ] `A#0 / MIDI 34` selects Quartal and the Voicing Type UI follows; Note On/Off is swallowed.
- [ ] V1 is the played melody, including an intentionally non-chord note.
- [ ] On an explicit extended chord such as Cmaj13, compare the same melody in Closed, Spread and Quartal. Quartal should favour adjacent fourths where the Stage 4 pool permits them; it need not repeat Closed pitch classes.
- [ ] On a plain triad, Quartal does not manufacture 9/11/13 merely to complete fourths.
- [ ] On Bm7b5 and an explicit #11 chord, characteristic/explicit chord material remains audible.
- [ ] On Cmaj7/E or G7/B, V4 retains the explicit slash bass.
- [ ] Compare Clean/Color/Rich on a confirmed V7 → minor and an unresolved dominant. No unsupported target or altered pitch should be invented; identical output on a constrained vertical is allowed.

## Host/state checks

- [ ] Switch Closed ↔ Quartal ↔ Spread ↔ Drop 2+4 ↔ Unison during a held note. No stuck or tiny notes.
- [ ] Save with Quartal selected, reopen, and confirm the selection. Older saved Voicing Types still restore correctly.
- [ ] MIDI 32/33 stay reserved and swallowed; MIDI 35..47 keep their prior controls.
- [ ] Repeated playback with identical input and state yields identical MIDI.

The low MIDI-domain fallback is tested in the host-neutral core; an instrument with a higher playable lower bound does not need an artificial below-range host passage.

0.4g is accepted only after the host checks pass. Windows CI alone does not establish Studio Pro behavior.
