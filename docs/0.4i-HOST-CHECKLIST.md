# Smart Voicing 0.4i — Studio Pro Cluster checklist

Use the paired Smart Voicing / Smart Voicing ARA VST3 package from a green Windows Build.

- [ ] `A0 / MIDI 33` selects Cluster in both UI and Sound Variations. The control Note On/Off never reaches downstream instruments. `G#0` still selects UST and `A#0` Quartal.
- [ ] On Cmaj7, play a middle-register C or E melody: V1 stays exactly played; upper notes sound compact and distinguishable from Quartal's fourth structure. V4 anchors the chord.
- [ ] On an explicit Cmaj9 or C7#11, select Clean: Cluster can use the written extension/alteration where a safe layout fits. It must not require Color/Rich to respect explicit chord material.
- [ ] On a plain C major triad in Clean, no 9/11/13 is invented. On Bm7b5 and an explicit #11 chord, characteristic/altered notes remain authoritative where a safe layout fits.
- [ ] On Cmaj7/E, V4 keeps E lowest. A melody note outside the chord remains V1.
- [ ] Switch Cluster ↔ UST ↔ Quartal ↔ Closed with held notes, repeated notes and sustain: no stuck or tiny notes.
- [ ] Save/reopen with Cluster selected; previous projects retain their earlier Voicing Type. Very low MIDI preserves V1 without wrapping.
- [ ] Repeated playback of the same input produces the same notes. Tension 43..45 and Harmony Mode 46..47 controls retain their mappings.

After Cluster is host-confirmed, use `docs/STAGE5-CLEAN-ACCEPTANCE.md` to review all voicing shapes in Clean. Evaluate Color/Rich enrichment of basic chords in Stage 6 (#10).
