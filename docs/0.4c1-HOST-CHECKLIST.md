# Smart Voicing 0.4c1 — Unison host checklist

Use the latest `Smart-Voicing-0.4c-Windows` artifact after the host-integration CI is green.

## Studio Pro smoke test

1. Open Smart Voicing in `Melody Harmonize` mode.
2. Select `Voicing Type = Unison`.
3. Play/record a short monophonic melody.
4. Verify Ch1–Ch4 receive the same MIDI pitch for every melody note.
5. Change `Clean / Color / Rich`: Unison pitches must remain unchanged.
6. Cross Chord Track boundaries while holding a melody note: the Unison pitch must not reharmonize.
7. Repeat the same melody note several times: all four channels must rearticulate cleanly.
8. Release the note: all four voices must receive Note Off; no stuck notes.
9. Switch live `Closed → Drop 2 → Unison → Closed` while a note is sounding: no stale voices or tiny garbage fragments.
10. Save with `Unison`, reopen the project, and verify `Unison` is restored.
11. Open a project saved with 0.4a/0.4b and verify its old `Closed` / `Drop 2` value is preserved.
12. Confirm Tension keyswitch notes remain swallowed and do not appear on downstream instrument tracks.

## Pass condition

0.4c1 is accepted when Unison behaves as a four-channel melodic section texture, remains independent of harmonic tension selection, survives save/reopen, and switches cleanly against the accepted harmonic voicing types.
