# Smart Voicing 0.4h — Studio Pro UST checklist

Run this only after the UST branch's full Windows build is green and the current Quartal test is resolved. Use the paired Smart Voicing and ARA VST3 package.

- [ ] `G#0 / MIDI 32` selects UST in UI and Note On/Off does not reach the downstream instruments. `MIDI 33` remains reserved.
- [ ] On Cmaj7 with a melody note E, upper voices form a recognizable Em triad over a structural support note. V1 remains exactly E in the played octave.
- [ ] On Cmaj7/9 with melody D, compare UST to Quartal and Closed. UST must choose a triad from the legal Stage 4 material, not rename another strategy's output.
- [ ] On a non-chord melody note, the played V1 survives; a partial upper triad is acceptable when a complete legal one cannot fit.
- [ ] Plain triad: no invented 9/11/13. On Bm7b5 and an explicit #11 chord, characteristic and explicit tones stay authoritative when a safe layout exists.
- [ ] Slash-bass chord Cmaj7/E: V4 keeps E. Compare a confirmed V7 → minor and an unresolved dominant at Clean/Color/Rich; no assumed resolution or unsupported altered triad appears.
- [ ] Switch Closed ↔ UST ↔ Quartal ↔ Spread during a held note: no stuck or tiny notes.
- [ ] Save with UST selected and reopen. Previous projects saved with 0.4g and earlier types retain their selection.
- [ ] Same inputs/state on repeated playback yield the same MIDI. MIDI 34..47 controls remain mapped as before.

Windows CI and a printed score are separate evidence from realtime Studio Pro acceptance.
