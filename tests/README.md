# Тесты Smart Voicing

Этот каталог зарезервирован для автоматических тестов проекта.

На Этапе 0 здесь фиксируется структура репозитория. Начиная с этапов Harmonic Context и MIDI Engine сюда будут добавляться unit-тесты для:

- выбора гармонического контекста по позиции timeline;
- интерпретации аккордов и тональности;
- распределения MIDI-голосов;
- voicing и voice leading;
- граничных случаев Note On / Note Off / sustain.
